3) Gợi ý dùng cho demo dns rewrite (doh-server.js RULES)
   - Muốn "rewrite" sang IP gateway/proxy của bạn: { domain: 'spclient.wg.spotify.com', action: 'ip:<IP_CUA_BAN>' }
   - Muốn chặn domain ads/log: { domain: 'audio-ak-spotify-com.akamaized.net', action: 'zero' } hoặc 'nxdomain'
   - Không rewrite (forward bình thường): bỏ rule hoặc action 'passthrough'
   Lưu ý: chỉ rewrite DNS (trả A/AAAA/NXDOMAIN) không thay được nội dung API HTTPS như tweak/gateway MITM.
